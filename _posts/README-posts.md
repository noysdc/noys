# پوشه‌بندی پست‌ها

- `magazine/` → پست‌های متنی مجله (نوشتاری، حتی اگه پادکستشون هم همون‌جا باشه)
- `podcast/`  → پست‌هایی که صرفاً برای یک اپیزود پادکست ساخته می‌شن (بدون متن مفصل)

⚠️ نکته‌ی مهم فنی: جکیل به‌صورت خودکار اسم همین پوشه‌ها (magazine و
podcast) رو به‌عنوان «دسته» (category) به هر پستی که داخلشونه اضافه
می‌کنه. این کاملاً طبیعیه و روی لینک نهایی پست هیچ تأثیری نداره
(چون permalink سایت بر اساس عنوان پسته، نه پوشه یا دسته)، فقط برای
اینکه این دو تا اسم انگلیسی وسط موضوعات فارسی سایدبار (نظامی، قاچاق و
...) ظاهر نشن، توی `_layouts/main.html` و `categories.html` به‌صورت
دستی فیلتر شدن.

یعنی: خیالتون راحت باشه، فقط با جابه‌جا کردن فایل‌ها بین این دو پوشه،
نه لینک‌ها خراب می‌شه و نه دسته‌بندی‌های واقعی سایت شلوغ می‌شه.

نحوه‌ی اسم‌گذاری فایل هم مثل همیشه‌ست: `YYYY-MM-DD-عنوان-انگلیسی.markdown`

# پست‌های اپیزود پادکست (فیلد `podcast_audio`)

پخش اپیزودها مستقیم از فایل صوتی (mp3) فید RSS انجام می‌شه. برای هر پست
داخل `podcast/` فقط همین یک فیلد لازمه، زیر خط `img:` توی front matter:

```yaml
podcast_audio: "https://play.rabt.host/podcast/<id-پادکست>/episode/<id-اپیزود>/play.mp3"
```

آدرس رو از تگ `<enclosure url="...">` همون اپیزود توی فید RSS کپی کن.

- پلیر شناور، صفحه‌ی `/podcast/`، دکمه‌ی «▶ پخش این اپیزود» و پلیر پایین
  متن پست، همه از همین فیلد می‌خونن.
- اگه پستی این فیلد رو نداشته باشه، دکمه‌ی پخشش نمایش داده نمی‌شه
  (توی `/podcast/` یه یادآوری کوچیک می‌بینی).
- فیلدهای قدیمی `podcast_channel_id`، `podcast_episode_id` و `podcast_id`
  دیگه استفاده نمی‌شن و باید حذف بشن.
- برای پست‌های مجله که نسخه‌ی صوتی هم دارن، همین فیلد `podcast_audio`
  رو بذار تا پلیر «🎧 نسخه صوتی پادکست» پایین مطلب نشون داده بشه.
